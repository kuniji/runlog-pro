Garmin Connect データ取込

Garmin Connectから書き出した FIT / TCX / GPX をiPhone上で読み込みます。FITは距離だけでなく、時間・平均心拍・ケイデンス・標高などを自動取得します。

ファイルを選択してください。

今回の改善ポイント

  • FITを手入力する必要なし
  • GarminのバイナリFITをブラウザ内でデコード
  • 距離・時間・ペース・心拍・ケイデンス・獲得標高を可能な範囲で自動登録
  • Garmin APIは使用しないため、Garmin Developer Programの承認は不要

FIT解析にはGarmin公式FIT JavaScript SDKをブラウザから読み込みます。SDKはブラウザ対応のECMAScript moduleとして提供されています。
